# Student Management System SQLite

A simple Student Management System built using Python and SQLite.

## Features

* Add Student
* Show Students
* Search Student by ID
* Update Student Information
* Delete Student
* Count Students

## Technologies Used

* Python
* SQLite3

## How to Run

1. Install Python
2. Run the program:

   python student_management.py
